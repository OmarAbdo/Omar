CourseNow

Privacy policy

Last updated: 9 October 2026

CourseNow is a desktop app written by Omar Abdo for his own use. It runs on the user's own computer. There is no CourseNow server, no user accounts and no analytics. This page describes what the app does with data, in particular with data from a Google account.

What CourseNow accesses in a Google account

CourseNow asks for one permission, the Google Calendar scope calendar.app.created. With it the app can create secondary calendars and read, add, change and delete events in calendars that it created itself.

It cannot access calendars it did not create, and it does not request access to any other Google data: no e-mail, no contacts, no files, no profile information.

What CourseNow does with that access

It creates one calendar named “CourseNow” and keeps it equal to the user's course plan: the titles, times and rooms of course meetings, deadlines, and a short note on the registration state of each course. It reads the events of that calendar back only to work out what has to be added, changed or removed.

Where data is stored

  • The Google access tokens are stored in a file on the user's own computer and are sent only to Google.
  • Calendar events are stored in the user's own Google Calendar.
  • Nothing is sent to the developer or to any other party. The developer has no copy of any user's data.

Sharing and other uses

CourseNow does not share, sell or transfer Google user data to anyone. It does not use the data for advertising, and it does not use it to develop, improve or train artificial intelligence or machine learning models.

CourseNow's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • “Disconnect” in the app revokes the access and deletes the stored tokens.
  • Access can also be removed at any time under myaccount.google.com/permissions.
  • The “CourseNow” calendar and its events can be deleted in Google Calendar at any time.
